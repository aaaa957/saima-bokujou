# 当前比赛引擎评估：现实参照和比较口径

本文件提供现实参照，不调整引擎参数，也不将观测分布转化为跑法奖励或固定发动距离。机器数据见 `current-engine-reality-sources-2026-10-02.json`，对应评估引擎提交 `582ce9046dd8552d950d0296e8500a8234388eff`。

## 来源与样本

沿用此前选定的 2023–2025 年 18 场 JRA 草地 G1：每年各一场1200、1600、2000、2400、3000、3200米。逐马成绩重新从 JRA 日文结果页提取；旧库保存的 JAIRS/JRA 赛事首马分段继续作为分段来源。每场 JSON 都保留两个直接来源链接。例：[2025 安田记念日文全场结果](https://jra.jp/datafile/seiseki/g1/yasuda/result/yasuda2025.html)、[同场 JAIRS 官方报道与分段](https://japanracing.jp/_news2025/250608.html)。

结果表共295条报名记录，实际293次出走、289次完赛、4次中止、2次取消。2024天皇赏春和2025日本杯各有一匹取消，实际各17匹出走；旧参考库 `fieldSize=18` 包含取消记录。本次单独保存 `entryCount`、实际 `fieldSize`、逐马 `isStarter`，不改写旧库。出马数范围11–18，中位17，均值16.28。取消、除外不进入出走分母；中止进入出走分母，但缺失完赛时间不参与速度、时差、上り分布。

本样本是**六项赛事的精英草地参照**。每个距离只有3场，距离同时绑定赛道、赛事、年龄和参赛群体。此前2025资料已被查看，本次是诊断复用，不再声称它是未见过的独立保留集。泥地、较低级别、极端湿地、不同栏位与风向不能据此判断已经拟合。

平均速度采用名义比赛距离/完赛时间；末600平均速度采用600/该马末600时间。这些数值不是实际外绕路径速度，也不是瞬时最高速度。JRA结果的完赛时间精度为0.1秒，照片判定的短着差可以对应相同显示时间。研究瞬时最高速度、加速或刹车时不能将200米均速当成逐帧实测。

[JRA结果字段说明](https://www.jra.go.jp/JRADB/mikata/result.html)明确：200米分段是各里程桩**首马**到达的时间；括号马群表示小于一马身的并行，并按内外顺序排列；上り3F指末600米。首马可能变化，所以首马全场分段不是冠军的完整个人速度曲线。JSON 的 `raceSectionals200m`、`first600`、`raceFinal600` 属于首马里程桩口径；`horses[].final600` 是逐马口径，两者分开保存。

新增 `leadingMarkerSpeedMetrics` 可对照首马速度形状：首200米中位12.55秒；最快200米中位11.00秒（18.182m/s），最短9.9秒（20.202m/s）；末200米中位11.70秒；末200米减前一200米时间的中位为+0.35秒。峰值很受赛道和具体赛事影响，不能将20.202m/s设成每匹马的统一目标或上限。

“不超过1秒／2秒”占比分母为该场有完赛时间的马，中止不计入分母。全场第一—最后时差包含真实尾部异常，不能因为冠亚军靠近就认为整个马群也紧密。

18场冠亚着差中有6场ハナ/アタマ/クビ，另12场为数值马身。保留原始标签，不擅自规定鼻、头、颈等于多少米或马身。12场数值子集中位2.0马身，不能冒充18场总体中位。利用6场短着差均位于半马身以下的排序，18场总体中位和P90可确定为1.25与2.8马身，最大4马身；此计算没有给短着差指定换算值，整体均值与最小值不报告。

引擎的冠军冲线瞬间沿程距离差，与现实照片判定的头部着差还有路径、姿态、长度定义的区别。直接外部比较优先用完赛时间差，马身仅用于尺度和分布旁证。

## 末弯位置代理和胜率分母

JRA这些公开成绩页没有统一的四跑法字段。本次统一比较采用：**末弯官方报出名次1→逃；2至ceil(N×0.375)→先；其后至ceil(N×0.625)→差；其余→追**。这里N是实际出走数，字母字段分别为 `front/prominent/midpack/rear`。它是一次比赛的末弯位置代理，既不等于赛前惯用跑法，也不等于引擎80米至80%赛程的平均位置分类。

并行马可能共享同一报出名次。JSON保留 `lastCornerRankReported`，并以同名次组大小给出 `lastCornerRankRange`、`possibleLastCornerProxies`；组内不按内外顺序假造前后排名。点统计按报出名次分类，跨分类边界者另保留不确定区间。仅有前期弯道记录的中止马不当成末弯；3次出走没有末弯记录，不参与末弯代理胜率分母。

[JRA脚质词典](https://www.jra.go.jp/kouza/yougo/c10180_list.html)将脚质描述为马匹擅长的比赛战术。这与末弯位置代理有概念差别。官方另一个赛事样本，[NAR东京短途锦标2022年前10届统计](https://www.keiba.go.jp/dirtgraderace/2022/0420_tokyosprint/analysis.html)，给出逃6/19、先4/38、差0/57、追0/33（大井外圈1200米泥地）。该表未公开具体分类算法，只作不同赛事条件下分布可以明显不同的背景参照，不与本次草地代理分类直接做合格判断。

## 可辅助判断系统机制的原始研究

[Spence等，2012](https://pubmed.ncbi.nlm.nih.gov/22399784/)分析英国3357场、44803次马匹出走，距离1006–4225米，每秒追踪。研究报告部分马匹峰值超过19m/s，第一与第五名平均速度差约0.13m/s（0.9%）；总体速度分化常集中在末约500米，跟跑与表现相关。可检查引擎马群速度何时分化、前后位置是否能转换；这些结果不构成固定500米发动规则或精确日本距离跑法目标。

[Self等，2012](https://pubmed.ncbi.nlm.nih.gov/22678967/)跟踪Goodwood的33场、373匹马，发现上坡与下坡均可能减速；观察斜率约为每1%坡度0.68m/s的上坡损失及0.45m/s的下坡损失。这是特定赛道的关联，不能直接搬成统一系数。它适合检查现有系统是否只有势能下降带来的省功，缺少下坡支撑、稳定性或控制成本。

## 已验证与仍不可比较的边界

采集时每场报名记录数与原有字段核对；18场冠军完赛时间和末600均与原库完全一致；源页面保留逐马状态和各弯道编号。新JSON可重算所有统计，没有修改 `sim.js` 或既有参考库。

目前可以比较名义完赛速度、首马分段形状、逐马末600、完赛时间离散、末弯位置到最终名次转换；可以记录工程内部的储备、功率、实际路径、堵塞与发动过程，用于解释偏差。公开成绩没有逐马连续GPS轨迹、全程个人200米分段、实测VO2/乳酸/推进功率、实时风场和赛道含水量，因此这些量**仍未获得现实拟合证明**。最终诊断应把结果偏差、可疑机制、已证实原因分别陈述。
