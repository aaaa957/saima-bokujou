# 个体生理分化 · v2026.10.02.3

本轮把持续供给、短时储备容量与释放功率、运动经济性、供能建立速度、疲劳耐受拆开。跑法只是展示标签，没有引入跑法或固定距离倍率，也没有改变 `RACE_F` 的全局基准。

## 研究依据和证据边界

- [Mercier & Aftalion（2020），Optimal speed in Thoroughbred horse racing](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0235024)：把运动、供能和控制耦合；论文中的马匹参数也是依赛速估计，不能把模型参数当成直接生理测量。这里沿用机械等价 W/kg、J/kg。
- [Eaton 等（1995），Maximal accumulated oxygen deficit in Thoroughbred horses](https://pubmed.ncbi.nlm.nih.gov/7615470/)：6匹训练纯血马的跑台实验中，无氧能力估计与最大有氧能力未见相关。因此不再把二者强制设成一个个体轴。小样本和跑台协议不证明现实群体相关严格为零。
- [Geor 等（2000），Effects of warm-up intensity on kinetics of oxygen consumption](https://pubmed.ncbi.nlm.nih.gov/10850838/)：标准bred跑台研究显示，供能建立速度可以变化而峰值不显著变化，支持将动力学时间常数与最大供给分离。模型没有把该论文的百分比直接当成当前纯血比赛系数。
- [Mukai 等（2021），Four weeks of high-intensity training … running economy](https://pmc.ncbi.nlm.nih.gov/articles/PMC7897453/)：训练研究分别测量有氧能力与运动经济性，支持把经济性作为独立通道。新参数范围和协方差都是有界结构假设，尚待个体实测标定。

这不是 VO₂、乳酸、肌纤维或遗传率的精确复刻；没有以增大无界随机噪声制造末600米极差。

## 持久化与迁移

`h.physiology = { version: 1, endurance, power, economy, kinetics, durability }`。五个轴均为 `[-1, 1]` 的有限数值。`neutralPhysiology()` 返回全零对照；`horsePhysiology(h)` 补齐并持久化。

首次取样用身份、初始属性与独立盐的稳定哈希，不消耗生成、繁育或比赛 RNG，不读取跑法标签。已有档案优先使用；旧马在比赛入口、首次训练或周年成长前补齐，训练后不重新取样。没有为每场比赛重新生成体质。

共同因子允许供能建立、耐受与持续供给部分协变；持续供给与短时容量是不同轴。新马、玩家马、AI马、初始种马、退役种马、赛事入口和幼驹均保留档案。繁育是亲代有界档案的加权均值加独立有界创新，并非已测量的遗传率。存档继续使用现有图格式，不升级存档版本；可选档案验证拒绝未知版本、缺字段、非有限值与越界值，旧档缺字段仍可载入。

## 实际物理通道

以下幅度是轴取极值、属性70时的范围；不是生成群体的标准差。

| 通道 | 个体化方式 |
|---|---|
| 最大持续供给 | 既有耐力供给基准 × `(1 + 0.05 × endurance)` |
| 短时储备容量 | 既有耐力储备基准 × `(1 + 0.10 × power)` |
| 短时释放功率 | 基准 × `(1 + 0.12 × power)`，另随当前爆发属性响应 |
| 运动经济性 | 既有经济性映射 × `(1 − 0.025 × economy)` |
| 供能建立时间常数 | 基准 × `(1 − 0.20 × kinetics)`，另随当前耐力响应 |
| 疲劳容限 | 既有毅力容量 × `(1 + 0.10 × durability)` |
| 疲劳后的供给下降 | 基准下降幅度 × `(1 − 0.20 × durability)` |
| 做功/额外出力引起的疲劳 | 小幅随持续供给、耐受轴响应 |
| 低功率恢复 | 仍受限恢复率和恢复功率，小幅随持续供给轴响应 |
| 最高速度约束 | 既有速度/爆发上限 × `(1 + 0.006 × power)` |

预测器与实际执行都读取个体供氧时间常数及短时功率；成本函数读取个体经济性，实际账户读取个体疲劳与恢复参数。没有修改制动、曲线或交通系数。当前属性与固定体质共同决定派生能力，因此训练仍有效。

中性档案在全70属性时保留旧基准。由于新增加当前耐力→供能建立、爆发→储备功率的通道，非70马的“中性档案”只是关闭五轴异质性，不是完整回滚到 v8。

## 验证

命令：

```text
node tests/individual-physiology.js docs/individual-physiology-v2026.10.02.3.json
node tests/physiology-save.js
node tests/roster-physiology-entry-v9.js
node tests/source-snapshot-equivalence-v9.js
```

前者8组机制检查通过，后者4组存档检查通过。机制检查含5,000个不同身份档案、18场跨距独跑、同目标出力储备对照以及一对8匹同阵容跑法重标比赛。每场独跑检查做功＝有氧已用＋储备支出、储备余额＝初值−支出＋恢复，未支付做功低于 `1e−6 J/kg`。多人重标对照的各马名次、时间、末600米和做功完全相同。

5,000个固定70属性样本的轴均值分别为0.00928、0.00089、0.00295、0.00747、−0.00261；持续供给与储备容量轴相关系数0.01966。由零中心线性乘数形成的最大持续供给均值偏移约+0.046%，储备容量偏移约+0.009%。这不是新生成合成阵容的比赛拟合结果。

## 尚未验证的部分

耐力属性仍参与两种供能基准，速度仍参与旧经济性映射，尚无个体生理测量为这些属性映射定标。预测器仍把当前疲劳水平外推，尚未预报未来疲劳曲线；真实参赛选择、能力协方差、动态抢口和兴奋状态也未通过这轮自动补齐。应结合根任务同马群、同种子的 v8/v9 与中性档案消融，判断末段分化、群体差距和冠军时间，而不能仅凭上述机制测试宣布实赛拟合完成。
