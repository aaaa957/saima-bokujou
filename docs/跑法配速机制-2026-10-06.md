# 跑法/位置意图进入配速请求（2026-10-06）

> 承接 `docs/变道插空机制-2026-10-06.md` §八：真正的病灶是**马群拉不开**，
> 根因是**所有骑手都用同一个 `budgetSpeed`（最大可支付恒速）**，配速几乎相同。
> 本轮把「跑法 / 位置意图」接到**配速请求**上。

---

## 一、改动（`sim.js`）

### 1.1 新增参数

```js
// RACE_F
paceIntentSpan:0.05,   // 跑法/位置意图对配速请求的最大偏置（±比例）
```

### 1.2 在 `runAI` 里把意图接到请求速度上

```js
const frontBias = clamp((plan.position-0.5)*2,-1,1)*0.6 +
                  clamp((behavior.forwardness-0.5)*2,-1,1)*0.4;
const earlyWeight = clamp(1 - H.s/Math.max(1,length*0.35),0,1);
const intentV = Math.max(3, Math.min(H.maxV,
  planned*(1 + frontBias*RACE_F.paceIntentSpan*earlyWeight)));
```

并把基准候选的请求从 `planned` 换成 `intentV`：

```js
const baseline = evaluate(H.startSettled?'settle':'start',
  [{duration:horizon, targetV:intentV}], holdT);
```

### 1.3 设计依据（为什么形状是自然涌现的）

- **抢前型前压、后追型收后**：`plan.position` 高（想领跑）⇒ `frontBias>0` ⇒ 请求更快。
- **偏置只施加在早段**（`earlyWeight`），中后段交回 `budgetSpeed`：
  前压者的储备更低 ⇒ 复算出的 `planned` 自然回落 ⇒ **拱形配速是结果，不是硬编码**。
- 请求超出功率上限时由 `projectionMove` 自身按 `supply.maxPower` 二分下压
  （`work>maxPower` 分支），因此**不会产生不可行轨迹**——只是请求"要不到"。

## 二、实测

### 2.1 关键否证：它**没有**让马群拉开

`tests/lane-gap-probe-v11.js` / `tests/start-spread-diagnostic-v11.js`：

| 出发 10 s 纵向跨度 | 改前 | 改后 |
|---|---:|---:|
| `spread10` | 5.1 m | **5.1 m（未变）** |

⇒ 跑法配速**不是**通过"打开空档"起作用的。前 24 秒仍然没有合法变道。

### 2.2 但它仍然带来了实质改善（`tests/spread-source-probe-v11.js`）

| 距离 | 闸位 ρ | | 速度 ρ | | 首末差 | |
|---|---:|---:|---:|---:|---:|---:|
| | 改前 | **改后** | 改前 | **改后** | 改前 | **改后** |

| **2000 m** | 0.700 | **0.553** ✅ | −0.252 | −0.281 | 2.05 s | **1.05 s** |
| **3200 m** | 0.930 | **0.754** ✅ | −0.038 | **−0.425** ✅ | 2.25 s | 5.35 s |

**完成密度（1200 m）**：`within1` **35.7% → 42.9%**（现实 58.9%）。

### 2.3 起作用的是哪条路（诚实结论）

- 配速意图引入了**与闸位无关的方差** ⇒ 稀释了"闸位决定名次" ⇒ 长途的闸位 ρ 明显下降。
- 各马的**储备轨迹开始分化**（前压者更早耗尽）⇒ 名次重新由能力参与决定
  （3200 m 速度 ρ 从 −0.038 变到 **−0.425**）。
- 但**空档并没有更早出现** ⇒ 1200 m 的锁死没有被解开。

## 三、判断

| 项 | 结果 |
|---|---|
| 跑法/位置意图进入配速 | ✅ **已接通**（这是本项目"跑法"第一次真正接到物理上） |
| 长途闸位依赖 | ✅ 2000 m 0.700→0.553、3200 m 0.930→0.754 |
| 能力重新参与 | ✅ 3200 m 速度 ρ −0.038→**−0.425** |
| 完赛密度（1200 m） | ✅ within1 35.7%→**42.9%** |
| 1200 m 闸位依赖 | ❌ 0.992→0.984（未解开） |
| 3200 m 首末差 | ⚠️ 2.25→5.35 s（出现"前压过猛被吞"的马；现实 4.19 s，**反而更近**） |
| 马群拉开 | ❌ **未发生**（spread10 仍 5.1 m） |

**⇒ 这是一次净改善，但不是终点**：它把"跑法"接上了，也把长途的闸位依赖压下来了；
但**"出闸后迅速拉开"这一环仍然缺失**，1200 m 因此仍被锁死。
下一步应补**起步/早期展开**（方法 3：现实里出闸质量与早期加速的个体差异远大于引擎现状），
而不是继续加大配速偏置。
