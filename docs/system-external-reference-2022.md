## 口径和提取校验

1. 逐马名次、时间、末600米、末弯通过顺位、负重与体重直接取自JRA日文官方结果表。200米分段同样取自该页的ハロンタイム，六场分段总和均等于冠军显示完赛时间，精度保留0.1秒。
2. 200米分段是首马经过里程桩的记录，首马可能更换；该曲线不是冠军完整的个人速度曲线。逐马末600米和首马末600米分别保存。
3. 完赛人数、出走人数、取消和中止分别计数。距冠军1秒/2秒占比分母为有完赛时间的马；中止仍留在出走数。
4. 末弯主分类使用各马结果表自身报告位置：1为front，2至ceil(N×0.375)为prominent，再至ceil(N×0.625)为midpack，其余rear。它是位置代理，不冒称官方统一跑法。
5. 保留括号并行组的原文、可能秩范围和跨类别歧义，不自行按马号排序。不能一律强制全组等于最小秩：2022安田末弯`(*5,4)`中，4号官方逐马报告位置是2。既有研究的组口径不用于覆盖官方原值。
6. ハナ、アタマ、クビ、大差保持原始标签，无数值换算。官方显示冠亚0.0秒仍可以由照片判出胜负，不解释为真实完全同时到达。
7. 六场都有完整的冠军、逐马及首马分段；102名完赛者均有有效完赛时间和末600米，103条记录的马号各场唯一，末弯报告秩均在相应并行组的可能范围内。每个来源保存所取HTML的SHA-256，便于追溯。

数据文件含 `races[].horses`，与此前全场参照字段兼容，并增加 `winner`、各场 `summary`、`direction`、`courseDescriptionRaw`、`cornerPassageGroups` 和取消/中止计数，方便后续固定阵容与种子检验。
