# 报名预测成本对照

冻结同一引擎文本，在内存中只改两处工作量：取消二分之前无用的 3 m/s 全程积分；对已经出现不可逆不可支付需求的二分调用使用 `earlyExit:true`。九次二分顺序、可行性判据、完整可行预测和没有可行结果时的 3 m/s fallback 均保留。生产由主代理整合。

1200 m、level 70 与 3200 m、level 86 各取 12 位固定候选，选出 8 位。原算法和优化算法的全部入选身份、eligible/fallback、预测窗口及每位入选马的完整预测逐字段严格相等。

| 条件 | 原积分步数 | 优化步数 | 减少 | 原/优化 user CPU |
| --- | ---: | ---: | ---: | ---: |
| 1200 m / level 70 | 155416 | 42076 | 72.9% | 625 / 313 ms |
| 3200 m / level 86 | 287385 | 98070 | 65.9% | 500 / 109 ms |

原 wall time 813/989 ms，优化 742/343 ms；这是小样本顺序执行，暖机与机器负载会影响时间比，积分步数更可靠。这不是全生涯启动时间承诺。对照 JSON 保留源 hash、精确替换片段和计数。脚本也能在已经优化的生产源上构造原算法反事实。

运行：`node tests/cohort-forecast-cost-v11.js`。不修改生产文件，不更新比赛真实性矩阵。
