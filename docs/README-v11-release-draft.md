# README v11 发布文案草稿

以下文案需在最终源码、参数和验收记录冻结后交由主代理更新README。目前数值筛选仍在运行，不能直接发布“验证通过”的声明。

本轮将骑手预测和实际执行接到同一套运动、跟驰及供能求解器上；骑手比较有限抢位、跟跑后追回、等待通道和内线路线，承诺的动作分阶段实际执行。跑法由比赛中的位置与策略产生，不使用跑法速度或耗能倍率。

参赛阵容按实际距离、场地和赛级评估，已有马匹能力、生理和性格保留；修复未胜利赛零胜上限、条件赛胜场、重复玩家身份和阵容不足的记录。强马可以进入高级别赛事，不受最快参考端排除。生涯、下注和公开市场入口另做回归。

数值验收采用30个官方事件各1个固定预声明种子，覆盖全部既定距离与年份；加18次单马全程预测检验，共48次完整全程，以及108次至600米受控起步。旧72场基线全部保留，主表匹配旧seed0，旧3种子只作稳定性背景。早期六轴探索14/24行政停止，已测行、失败与未覆盖任务均保留。原90官方场方案在未读取2020模拟结果前，依据实测成本修订；新单种子数据不支持群体跑法胜率稳定或平衡的结论。

现实拟合与工程检查分开报告：冠军时间、个人末600米、首段、途中速度、首末差、冠军后1/2秒比例、个人末600米极差和领先者分段CV均按事件列出残差。目标位置与有限抢位已有，但对手意图推断、战术相互响应和配速生成仍有结构限制。短时出力与持续速度的关系也需进一步辨识；训练成本对照中储备明显下降而短途总时变化很小，提示下一步检验出力持续时间与疲劳恢复的耦合。它是结构假设，不是实测GPS或代谢结论。工程自洽不代表队列与节奏已拟合现实。
