# 先天前进意图的分布支持

原式把前进偏好绑到出闸能力减爆发力，再加 ±0.25 随机量。每级 35/70/86 各 1000 个相同生成 seed 的小抽样，在原实现中范围都是 0.1866–0.7351，`forwardness>=0.75` 为 0。该样本出闸减爆发力均值 −5.577，偏好中位数 0.4777，二者相关 0.145。这会让高前位意图在生成入口缺席，无法通过更完善的位置竞争自行涌现；它不是跑法胜率调参问题。

主代理已采用温和的 Beta(2,2) 全区间先验，只替换新马或缺失行为的前进偏好。它使用同一个均匀 RNG draw 的逆 CDF，能力只影响执行动作的物理限制。该抽样范围 0.0119–0.9843，>=0.75 占 16.7%，>=0.9 和 <0.1 各占 2.3%；与能力差相关 0.032，接近抽样噪声。

相同 seed 下，统计属性、生理档案、settle 与 tractability 完全不变。已保存的三项行为保持原值；缺失行为的稳定身份补齐不会随出闸/爆发力训练改变前进偏好。极端偏好的概率受到温和先验限制，仍由付费运动、交通和对手竞争决定实际位置。

这里的 16.7% 是数学先验及样本结果，没有声称它是现实逃马比例；赛后观察跑法也不是先验偏好的同义词。运行 `node tests/behavior-intent-review-v11.js` 可在当前生产源上构造原式/新式对照，JSON 保存精确片段与来源。
