## 一、配速的最优控制：Mercier & Aftalion 2020

- 出处：PLoS ONE 15(12): e0235024，DOI `10.1371/journal.pone.0235024`
  ｜预印本 arXiv:2006.10530（开放获取）｜PMID 33264298 / PMCID PMC7710124
- 数据：法国 Chantilly 约 10 场，France Galop + Mc Lloyd 追踪器，
  **10 Hz** 位置与速度，精度 **25 cm / 0.02 s**；三阶 Savitzky–Golay 平滑。

### 模型结构（【差异】本项目当前是"单请求速度预算"）

- 状态量：速度 `v(s)`、单位质量推进力 `f(s)`、无氧能量 `e(s)`。
- **方程写在"距离域"而非时间域**：把时间导数除以 `v` 换成对 `s` 的导数。
- 物理基础：牛顿第二定律 + 能量守恒（有氧贡献 `σ(e)` + 无氧 `e`）。
- 最优控制目标是**最小化完赛时间**，等价于 `min ∫ (1/v) ds`。
- 求解：**Bocop**（Inria 开源最优控制软件），**每 2 米一个离散点**；
  参数辨识用**双层优化 + 粒子群（pyswarm，50 粒子 / 150 代）**，
  目标 = 完赛时间差 + 1000 个测点的速度均方误差。

### 可用的具体数字

| 项 | 数值 |
|---|---|
| 有氧功率峰值 `σ_M` | **47 J/s/kg** |
| 换算后 `VO2max` | **≈133.6 ml/min/kg**（换算系数：1 L O₂ ≈ 21 kJ，×60/21） |
| VO2 达峰位置 | 约 **400 m**（起跑后 **20–30 s**，远快于人类） |
| 样本马达峰位置 | 1214 m / 839 m / 889 m（差异很大） |
| **VO2 开始下降的条件** | **剩余无氧能量降到初始的约 1/3 时** |
| 下降发生位置 | 约**距终点 500 m**；与终点前提速同时发生 |
| 无氧能量消耗曲线 | **起点与终点斜率最陡**，中段平缓 |

### 赛道与地形（三条可直接用的结论）

- 马被建模为**一根弯曲杆**：离心力**不直接进运动方程**，而是通过约束**限制推进力**，
  有效推进力形如 `f·√(1 − v²c/g)`（`c` 为曲率）。**【差异】** 本项目用的是
  `curveLateral` 推出的**弯道速度上限**，两者数学形式不同。
- 赛道：决赛直道前 **500 m 弯道**，前半段 **−1.5% 下坡**、后半段 **+2% 上坡**；
  最大弯道半径约 **100 m**。
- **上坡最好放在终点，下坡最好放在起点，弯道最好放在中段。**
- ⚠️ 核心警告：**地形/弯道不是局部扰动，而是改变整条速度曲线与平均值。**
  → 做"逐距离补偿"或"局部倍率"在方法论上是错的。

**【缺】** 论文明确把 **drafting（跟跑）与"马的心理"列为未来工作**，本模型未含对手。

## 二、生理实测值：VO2max、无氧容量、恢复

### Rose 等 1988（J Appl Physiol 64(2):781–788，DOI `10.1152/jappl.1988.64.2.781`）

8 匹纯血马，斜坡跑步机，`VO2` 与速度在 **10 m/s 以内线性**：

| 指标 | 实测值 |
|---|---|
| `VO2max` | **131–153 ml/kg/min** |
| **最大氧亏（无氧容量代理）** | **128 ± 32 ml/kg** |
| **氧债（恢复期）** | **324 ± 62 ml/kg**，约为人类的 **2–3 倍** |
| 肌肉 pH | 7.05 → **6.75**（恢复 1.5 分钟） |
| 血浆乳酸峰值 | **34.5 mmol/L** |
| 磷酸肌酸 PC | 恢复 ≤10 分钟内仍显著低于运动前 |

### 综述（PMC37685063，Hypoxic Training for the Equine Athlete）

- 纯血马 `VO2max` 跨研究范围 **≈100–160 ml/kg/min**，优于多数运动物种。
- 限制因素主要是**氧输送/供给**，而非线粒体氧化能力本身。

**【对本项目】** 这些是替换"体质/耐力代理"的**实测锚点**：
项目里 `aerobic`（J/s/kg）、储备容量（J/kg）应当能与
`σ_M ≈ 47 J/s/kg`、氧亏 `≈128 ml/kg O₂ → ≈128×21×1000/1000 ≈ 2.7 kJ/kg` 量级对上。

## 三、跟跑与空气阻力：RMIT 风洞 + Spence 2012

### RMIT 风洞（Fuss & Watkins，2014/2015；等比缩小马+骑手模型）

**不同构型下阻力变化（平均）**：

| 构型 | 效果 |
|---|---|
| 两匹马在前、一匹在后 | 后马阻力 **−66%** |
| 四匹纵队 | 末马 **−54%** |
| 两匹前后紧随 | 前马 **−6.5%**，后马 **−38.5%** |
| **五匹并列** | **中间那匹阻力 +25%** |

**【差异】** 本项目 `draftSave: 0.72`（即省 28%），低于实测的 **38.5%**（单马跟跑）。
**【缺】本项目没有"并列时中间马阻力增加 25%"这一项** —— 这是马群横向构型的真实代价，
可能正是"马群为何会散开、而不是永远挤在一起"的物理原因之一。

### Spence 等 2012（PMC3391435 / PMID 22399784；英国 2005–2007）

样本极大：**44,803 次出赛、3,357 场比赛**（10 个赛马场），
距离 1006–4225 m（50.9–292.9 s），射频追踪 0.8 Hz，位置精度 ±0.38 m。

| 指标 | 实测值 |
|---|---|
| 最高速度（98 百分位） | **19.05 m/s** |
| 阻力系数 / 迎风面积 | `Cd = 1.0`，`A = 1 m²` |
| **18 m/s 时阻力** | **209 N**，克服阻力功率 **3.8 kW** |
| 疾驰总机械功率 | **22.5 kW** |
| **空气阻力占总机械功率** | **约 17%** |
| 第 1 名 vs 第 5 名平均速度差（分崩后） | **0.13 m/s ≈ 0.9%**；全程约 **2%** |
| 该 2% 速度差可由**阻力减少 13%** 解释 | — |
| 跟跑占比赛 75% 时间的价值 | **约 3–4 个名次** |
| **马群"分崩点"** | 平均**剩余 478 ± 220 m**；长距离更早 |
| 分崩后**中位减速度** | **−0.080 ± 0.062 m/s²** |
| 中段减速度 | −0.0093 ± 0.040 m/s² |
| → 分崩后减速是中段的 **8.6 倍** | — |
| 92% 的马在分崩点后减速 | — |
| 遮挡判定 | 位于速度矢量两侧 **±10°**、距离 **5 m** 内（≈鼻到尾 2.5 m） |

**【对本项目最重要的一条】** 项目最难的指标是**完赛密度**：
现实"冠军后 1 s 内比例" 61–77%，模拟只有 12–31%。
Spence 给出的是一个**结构性机制**：马群会在**剩余约 478 m 处集体分崩**，
且分崩后所有人都以中段的 **8.6 倍**减速率掉速——**大家在同一处一起掉速，终点自然挤在一起**。
本项目目前没有"分崩点"这一现象级机制（只有个体的储备/疲劳），
只靠调参数无法产生"集体同时掉速"。**这是可验证的、可引用的缺失机制候选。**

## 四、战术与对手行为（项目自认的最大缺口）

### 项目现状（引自本项目文档）

> 「目标位置和有限抢位已实现，但**没有真实对手意图推断、随机化战术选择
> 及场内战术相互响应形成的配速共识**。」

### Willoughby（2017，赛马骑乘战术，PDF）

- 用"**energy/power 是货币、lengths 是商品**"的框架：**节奏快时 lengths 贵、节奏慢时便宜**。
- 便宜买 lengths 的位置只有两处：**起步**与**终点**。
- **明确用博弈论表述**：领跑者**有动机不跑太快**（跑太快既毁掉自己成绩，也抵消了领先省距离的好处）
  → 草地赛的步速**普遍偏慢于真实所需均值**。这就是"配速共识"的成因。
- 「对每一种策略都存在反策略（纳什均衡）」：追击者会预先施压逼领跑者**提前发力**。
- 3 浪到 1 浪之间是步速最热的区段——因为"挑战太晚"的代价（声誉与未来机会）很重。

### arXiv:2207.04981《What AI can do for horse-racing?》

把赛马博弈分成三层，可直接借用作为**分层建模清单**：

1. **赛季层**：是否参赛、骑师选择、眼罩/蹄铁、训练强度
2. **赛中层**：步速类型（慢/中/快）、内道还是外道站位、如何分配体能
3. **动作层**：**何时跟跑、何时进攻**
   - 并指出：马与骑手是"**肌肉与大脑分离**"——决策者要管理的是别人的肌肉，
     这正是本项目骑手建模的难点所在。
   - 引用 Spence：平均速度随"处于遮挡位置的时间比例"上升而提高。

**【对本项目】** 这段给了"对手意图 + 战术相互响应"的**概念结构与可引用出处**，
可作为把"运动 prior"升级为"战术相互响应"的理论依据（对应方法 3）。

## 八、VO2 动力学：把"VO2 下降"从猜测变成可测参数

> Langsetmo I, Weigle GE, Fedde MR, Erickson HH, Barstow TJ, Poole DC.
> *V̇O₂ kinetics in the horse during moderate and heavy exercise.*
> **J Appl Physiol 83(4):1235–1241, 1997.** DOI `10.1152/jappl.1997.83.4.1235`（PMID 9338433）

**这一条补上了 §六 列为"文献空白"的那一项**（M&A 论文写"没有精确估计 VO2 达稳态的时间"）。
方法：跑步机 square-wave 变速，逐秒测肺 V̇O₂；对比 3 m/s → 阈下 7 m/s 与阈上 12.3 ± 0.7 m/s。

| 量 | 实测值 | 备注 |
|---|---|---|
| V̇O₂max | **≈ 160 ml·min⁻¹·kg⁻¹** | 约人类顶尖选手的两倍 |
| 阈下（中等强度）相位 2 时间常数 τ₁ | **10.0 ± 0.9 s** | 马远快于人类（人 >20 s） |
| 阈下时间延迟 TD₁ | **18.9 ± 1.9 s** | 与人腿蹬车相近 |
| 阈上（高强度）τ₁ | **20.7 ± 3.4 s**（约翻倍） | TD₁ 不变（20.3 ± 1.2 s） |
| 达稳态所需 | **50–60 s**（人需 2–3 min） | 马极快 |
| **慢成分（slow component）出现时刻** | **剧烈运动开始后 135.7 ± 28.5 s** | 叠加在相位 1/2 之上 |
| 慢成分量级 | 约净 V̇O₂ 增量的 **12%**（5.8 ± 2.7 l/min） | 参数可直接用 |
| 热身/priming 效应 | 使 τ 缩短 **约 30%** | 起步前有预热时更明显 |
| 血乳酸（中等 / 高强度结束） | **1.2 / 8.1 ± 1.4 mmol·l⁻¹** | 阈值判据可参考 |
| NO 抑制（L-NAME，PMID 11457807） | 慢成分提前至 **65.0 ± 6.6 s**（对照 124.6 ± 11.2 s） | 说明慢成分是可被调控的生理项 |

**【对本项目】两条独立机制缺口：**

1. **起步段的有氧供给不是瞬时到位的。** 存在 ~19 s 的 TD₁ 加 10–21 s 的 τ₁；
   若项目把有氧供给当作"立即满额"，起步段会系统性偏快。
   阈值上下 τ 差一倍 → **"高强度跑"与"中等强度跑"应使用不同的时间常数**。
2. **慢成分（晚段 V̇O₂ 持续上升）。** 结合 Spence 的赛程跨度 **50.9–292.9 s**：
   **中长距离赛（>135 s）正好在末段进入慢成分**——这可能是"末段集体掉速"的**生理基础之一**，
   且它是**按运动时间触发**的，与几何、赛道位置无关。

> ⚠️ **不要与 M&A 的机制混淆**：M&A 说的是"剩余无氧储备 ≈1/3 时 V̇O₂ 下降"（供给耗尽），
> 本节说的是"高强度运动的 V̇O₂ 慢成分"（动力学滞后）。**两者方向相反、触发量不同，应分别建模。**

## 九、生成式帧级多马模型（架构级参考）

> *A generative approach to frame-level multi-competitor races.*
> **JQAS 2023**, DOI `10.1515/jqas-2023-0091`；开放版 arXiv `2310.01748`。
> 数据：NYRA / NYTHA 2019 一英里赛，**约 4 Hz**（帧长 ≈ 0.25 s，一英里 ≈ 350–400 帧）。

这是目前检索到**与本项目"方法 2 第 3 条（横向动力学）"最接近的已发表方案**。

**架构**：每帧位移拆成前向与横向两个分量，各自一个模型：

```
前向： y_for ~ N( θ_k(j)〔样条〕 + δ_jockey + δ_track + X_for·ψ , σ_f )
横向： y_lat ~ N( PLM·β_plm + δ_jockey + δ_track + X_lat·ψ , σ_lat )
```

- **PLM = 上一帧的横向位移，被明确称为横向模型中"最重要的协变量"**：
  帧间隔极短，正在向内或向外移动的马**倾向于继续该方向**——即**横向运动有惯性**。
- 骑师效应 δ_jockey 与赛道效应 δ_track 为随机效应，**均值固定为 0**（与样条项区分）。
- 作者**明确承认前向与横向"独立"是简化**，理由：Δt 很小（≈0.25 s），
  依赖信息大多已由滞后项与"当前是否在弯道"等协变量捕获。

**跟跑（drafting）的建模口径**（本项目可直接借用）：

- 用 **OpenFOAM（PISO 算法）** 算阻力系数，在 **3×3 网格**上求解：
  后方 **2 / 3.5 / 5 m** × 横向 **−0.5 / 0 / +0.5 m**，网格之间**线性插值**；另算"干净空气"基线。
- 阻力 `F_d = ½ ρ v² c_d A`，迎风面积 `A = 1 m²`。
- 派生出**两个协变量**：
  1. **瞬时二值**：当前是否处于跟跑收益位置；
  2. **累计量**：到该时刻为止**所节省的能量比例**（`E = ∫F_d ds`）。
- 简化假设：**只计最近前方一匹**的效应。

**计算可行性**：2000 次后验模拟 × 6 匹 × 400 帧 ≈ **9.6×10⁶ 次抽样**，
在 16 核 MBP 上 **90–120 s**；早期纯 R 版本要 5–10 min 且跑不到 50 次模拟。
→ 说明"帧级多马模拟"在合理工程下是可承受的，**卡的不是模型，是实现的常数**。

**【对本项目】三条可直接落地的东西：**

| 文献给的 | 本项目现状 | 动作 |
|---|---|---|
| 横向惯性 PLM（上一帧横向位移） | 横移只有速度上限，无持续侧向状态 | **【缺】最可行的补齐点** |

## 十一、对手册前几版的两处校正

1. **§六 的"VO₂ 达稳态时间常数是空白"已作废**——Langsetmo 1997 给了实测值（见 §八）。

2. **RMIT 数字漏了一项**：两匹前后紧随的构型中，**前马也有 −6.5% 的阻力收益**

## 十二、M&A 论文的可复用细节（补齐上一版略过处）

- 求解器：**Bocop**（Inria-Saclay，开源最优控制）。
- 参数辨识：**粒子群（pyswarm）**，50 粒子 × 最多 150 代；目标
  `min_p [ |t_simu(d) − t_data(d)| + (1/N)Σ(v_simu(s_i) − v_data(s_i))² ]`，**N = 1000**。
- 待辨识参数向量：`(τ, e⁰, f_M, d₁, d₂, σ_M, σ_f, u₋, u₊)`。
- 赛道几何表示：**直线（曲率 0）+ 圆弧（曲率常数）+ 回旋线 clothoid（曲率随距离线性变化）**
  ——回旋线是连接直线与圆弧的标准过渡，能让速度变化平顺。**本项目可用同一套几何原子。**
- Chantilly 实测地形：终直前有 **500 m 弯道**，其前 1/4 下坡 **≈1.5%**、后 1/4 上坡 **≈2%**。
- 数据处理：位置投影到参考赛道（使各马跑同一距离），速度用 **3 阶 Savitzky-Golay 滤波**平滑。
- 关键结论（再次强调）：**地形与弯道是全局影响**（改变整条速度曲线与平均值），不是局部扰动
  → **"逐距离补偿"在方法论上是错的。**

## 十三、步态与疲劳：一条新的、独立的验证轴

本项目目前**直接建模速度**，没有步频/步幅层。文献给出可实测的步态参数与"疲劳签名"，
这既是**又一处机制缺口**，也是一条**可从公开数据验证**的新输出轴。

### 基准步态（Deuel & Park 1993，PMID 8470461）

1988 首尔奥运三日赛，200 fps 高速摄影，108 个跑步周期：

| 量 | 实测值 |
|---|---|
| 速度 VEL | **12.09 ± 0.10 m/s** |
| 步幅 SL | **6.04 ± 0.05 m** |
| 步频 SF | **2.00 ± 0.01 /s** |
| 最佳成绩区间 | **SF 1.85–2.05 /s**，**VEL 13–14.3 m/s**；SL 至 7 m 仍无上限迹象 |

### 疲劳签名（Takahashi 等，J Equine Vet Sci，PMID 33993952）

2400 m 草地，同场比赛**第 1 圈 vs 第 2 圈**对照：

| 量 | 第 1 圈 | 第 2 圈 | 变化 |
|---|---|---|---|
| 速度 | 17.3 ± 1.3 m/s | 16.0 ± 0.9 m/s | **−7.5%** |
| 步频 | 2.34 ± 0.08 /s | 2.21 ± 0.09 /s | −5.5% |
| 步幅 | 7.42 ± 0.52 m | 7.25 ± 0.38 m | −2.3% |
| 对角步 | 2.32 ± 0.34 m | 1.88 ± 0.23 m | **−19%** |
| 后肢步 | 1.19 ± 0.09 m | 1.26 ± 0.10 m | +5.9% |
| 腾空步 | 2.43 ± 0.25 m | 2.61 ± 0.18 m | +7.4% |

**控制速度后**：步频 ↓、对角步 ↓，而后肢步/前肢步/腾空步/步幅 **↑**
→ 结论：**疲劳时马"身体展不开"**（无法伸展躯干），靠缩短对角步、拉长腾空来维持。

### 大样本分段（Morrice-West 等 2021，Equine Vet J 53(5):1063–1074，DOI `10.1111/evj.13370`）

**N = 25,259 次出赛**，GPS + 惯性传感器，按 **每 200 m 分段**统计：

| 量 | 均值 ± SD |
|---|---|
| 速度 | 16.63 ± 1.04 m/s |
| 步幅 | **7.08 ± 0.39 m** |
| 每 200 m 步数 | 28.32 ± 1.56 |
| 步时 | 0.43 ± 0.02 s |

**随赛程推进：速度与步幅下降、步数上升。**
关键警告：**速度只能解释步态变化的一半或更少**——即**不能用速度反推步态**。

**【对本项目】** 若引入步态层，可得到一条**独立于速度的现实校验轴**，
且步态数据在公开来源可查（HKJC 有"完歩ピッチ"概念、netkeiba 有"完歩"指标）。

## 十四、弯道与赛道几何：离心力、超高、过渡曲线

### 力学基础

离心力 ∝ **v² / r**（速度平方、半径反比）。无超高时，马只能靠**内倾 + 足部成角 + 摩擦**抵消
（Dalin 等 1973：不充分超高的弯道上，马左前肢内收、左前球节升温）；
进出弯时马必须**重新调整平衡**，对四肢载荷上升，**步态不对称集中出现在进出弯处**。

### 量化：弯道到底慢多少

**Arioneo**（商用追踪，Deauville 1600 m 草地，条件赛/让赛对比）：

| 项 | 结果 |
|---|---|
| 非直线赛道 vs 直线赛道 | **平均慢约 11%** |
| 差异最大区段 | **前 1200 m**（弯道所在） |
| 最后 400 m | 两者**几乎相同** |
| 最后 200 m | 弯道赛约慢 **2 km/h**（推测用于抵消离心力，能量不再留给冲刺） |

### 赛道设计（澳洲 RIRDC / Fredricson 等 1975）

- **超高（superelevation）表**：原报告给出了"曲线半径 × 速度"下的最佳超高百分比
  （半径 200–800 m 档、速度 666–800 m/min 档）。**总体规律：半径越小、速度越高，所需超高越大。**
  建议内半幅按最高速度设超高，中外道可较缓。
- **过渡曲线**：直线与圆弧之间插入半径渐变的过渡段（回旋线/缓和曲线），
  可减少进出弯失衡；**即使超高不足也有收益**（与 §十二 M&A 的 clothoid 用法一致）。
- **伤病聚集在主弯（home turn）**，应优先处理。
- 悉尼某赛道超高由 **4.8° → 5.7°**：伤病率由 **8.5 → 6.6 / 1000 出赛**。

### M&A 的对照实验（把几何效应单独剥出来）

把真实赛道分别替换为"仅坡度（直线）""仅曲率（平地）""平坦直线"三种理想赛道对比：

- **弯道强烈降速**；终点前**上坡无法提供与平地同等的加速**。
- 明确结论：**这些是局部效应，却改变整条速度曲线与平均速度 —— 即对策略有全局影响。**
  → 与 §十二「逐距离补偿在方法论上是错的」相互印证。

**【本项目】** 现状是"弯道用速度上限"；M&A 是"有效推进力 = f(s) 被曲率 c 削减"。
两者口径不同，但可**同时保留**（前者作为约束、后者作为力）。真正缺的是**进出弯的平衡调整代价**。

## 十六、M&A 补充：弯道内的速度曲线与 turnpike

来自该论文的开放预印本（`10.1101/2020.06.11.145797`）：

- **900–1400 m 段的弯道形态**：进弯时（该处下坡）马**略加速** → 离心力使其**降速** → 出弯**再次加速**。
- **V̇O₂ vs 距离**：约 **400 m 内上升** → 随后**恒定** → 最后在"**剩余无氧降到初值 1/3**"时**下降**。
- **推进力 f(s)**：起点即最大值 → 降到均值 → 终点前**强加速**；
  且明确指出：**这个强加速只能在出弯之后发生，因为弯道里离心力削减了可用推进力。**
- **turnpike 现象**：长距离赛出现"速度平台"，作者认为马的长距离配速也可用该数学工具分析
  （与人类赛跑的最优控制同源）。

> ⚠️ 再次强调**两套 VO₂ 机制不要混**：
> 此处"剩余无氧 1/3 时 V̇O₂ 下降"= **供能储备耗尽**（距离触发）；
> §八 的"慢成分"= **动力学滞后**（时间触发，约 136 s 后出现）。**方向与量都不同。**

## 十八、负重（斤量）对速度的定量影响

本项目有 `carriedWeight` 与 JRDB 的"斤量差修正"概念，但缺少**可引用的换算系数**。这一节把公开说法对齐。

| 来源 | 说法 | 折算 |
|---|---|---|
| **香港赛马会**（《香港商报》彼德講馬專欄，2022-06-26） | **每多负 2 磅**：短途消耗 **约 0.055 秒**；长途消耗 **0.11–0.22 秒** | 短途 ≈ **半个马位**；长途 ≈ **1–1.5 个马位** |
| 通行说法（Cartmel / Betmana，英国） | **5 磅 = 1 马身 ≈ 0.2 秒** | 每磅约 0.04 s |
| 美国某研究 | **3 磅**使成绩变差 **1 个马身** | 每磅约 0.067 马身 |
| 另一通行说法（Better Racing Analysis） | "**1 磅 ≈ 1 马身**（草地）" | 与上两条**量级不符**，疑为宽泛表述 |

**【对本项目】三条结论：**

1. **量级取 2–3 磅/马身**较稳妥（HKJC 与美国研究的区间）；"5 磅/马身"偏保守，
   "1 磅/马身"与其他来源差一个量级，**不要采用**。
2. **效应随赛程变长而放大**（HKJC：短途 0.055 s vs 长途 0.11–0.22 s）
   → 与本项目"长途对配速更敏感"的现象一致，**不应使用与距离无关的固定系数**。
3. 赛场规则锚点：BHA 称重容差为**低于 1 磅 / 高于 2 磅**；常规负重区间 **110–130 磅**
   （香港马会 2022 年 6 月起为 **115–135 磅**）。

## 十九、骑手的感知与决策（项目最大缺口的行为学依据）

### 反应时间是可测的、且能区分水平

- **新西兰赛马骑师体能研究**（Springer 2023，DOI `10.1007/s42978-023-00257-6`）：
  **本国有排名前 20 的骑师反应时间显著快于其余骑师**，且核心力量更强。
  研究者据此主张把**反应时间与决策**纳入骑师专项体能测试。
  → 意味着"骑师等级差异"在现实中有**可量化的行为学基础**，不只是力气大小。
- 通用量级：**常人反应时间约 0.25 s，训练有素的竞速选手约 0.15 s**。
- **周边视觉**训练可将高速情境下的事故率降低 **25–30%**（运动视觉诊所数据，非同行评审）。

### 决策的心理结构（可作为骑手 AI 的特征清单）

来自赛马心理学的整理（非同行评审，但结构清晰、可借用）：

| 环节 | 内容 | 对骑手建模的启示 |
|---|---|---|
| **模式识别** | 从其他骑手与马匹的细微动作预判其意图 | 「对手意图推断」的**现实依据**——人类靠观察前兆，不是解方程 |
| **威胁评估** | 持续评估被挤压、被逼出、马匹行为异常的风险 | 对应"安全余量"约束 |
| **策略思维** | 何时施压、何时收敛、何时换位 | 对应"抢位/保守"的离散决策 |
| **认知偏误** | 确认偏误、过度自信、可得性启发（近期坠马后过度保守） | 可作为**随机化与个体差异**的来源 |

**【对本项目】** 这段给了"配速共识"之外的另一个现实机制：
**骑手不是最优控制器，而是"模式识别 + 启发式"的决策者**。
这解释了为什么现实中会出现"大家同时掉速"（都在读同一个前兆）
以及为什么群体配速会**系统性偏慢**（领跑者不愿破风 + 挑战者倾向等待）。

## 二十、地面 / going（良 / 稍重 / 重）对速度的定量影响

**为什么单列一节**：本项目引擎目前**没有 going 维度**——`going`、`场地`、`稍重`、`重马场`
在全文中出现 **0 次**。所有场次实际上都是"默认良地"。
但现实里 going 是**与距离、负重同一量级**的成绩解释变量：
同一赛道同一距离，重地可以比良地慢**接近 6 秒**（下节实例）。
缺了这一维，"冠军用时/完赛密度"的残差里就混进了本可解释的系统性偏差。

### 唯一的同行评审量化研究（本节核心）

- **Hobbs SJ, Tatlisulu A, Johnson A, Rowlands SD, Lucey M, Martin JH, Graydon RW, Northrop AJ (2024)**
  *Unravelling the speed-going relationship: A proof of concept study from British turf flat and jump race meetings.*
  **J Equine Vet Sci 143:105211**。DOI `10.1016/j.jevs.2024.105211`，**PMID 39461450**。
  ⚠️ **开放获取 CC-BY**，但本机 C 盘紧张——**只记 URL/DOI，不要下载那个 2 MB PDF**。
  仓储地址：`https://knowledge.lancashire.ac.uk/id/eprint/53496`
- **样本**：**50 场英国草地赛事**（**25 场平地 + 25 场障碍**）。
- **方法**：用 **Vienna Surface Tester** + 水分仪测地表参数
  （cushioning 缓冲、firmness 硬度、depth 深度、energy return 能量回弹），
  与"由正规化冠军时间反推的 going"做回归（线性 vs 非线性模型对比）。
- **结论 1（最佳预测量）**：**cushioning（缓冲）**的
  **两段式多项式（two-phase polynomial）模型**是对"成绩反推 going"的最佳预测模型，
  **调整后 r² = 0.819，P < 0.001**。
  → **cushioning 单独一项就能解释约 82% 的地面—成绩关系**，比传统的"硬度"更有效。
- **结论 2（关键的非线性，最值得抄）**：马匹最高疾驰速度在较硬地面上更高，
  但**在 cushioning ≈ 10 kN 处出现平台（plateau）**。
  10 kN ≈ **两倍马体重**。**超过这个阈值后，地面再硬也不会更快**
  （作者推测是马匹通过改变**肢体触地时序**来管理受力上限）。
  → **going → 速度不是线性关系，而是"软化端陡、硬化端饱和"的单调饱和曲线。**
- **结论 3（软地 = 更大的方差，不是单纯的均值偏移）**：
  **软地上速度的变异性显著更高**，作者归因于"软而不稳"的表面更难驾驭。
  → 这一条与本项目**已知的完赛密度偏差**（冠军后 1 s 内比例 现实 76.8% vs 模拟 ~18%）**直接相关**：
  现实中的方差有一大部分本应由地面条件贡献，而我们的引擎把它全算进了"随机性"或"骑手差异"。

### 官方 GoingStick 尺度（可直接当离散档位表用）

来自**英国赛马管理局 / Jockey Club**（2003-12-02 启用公告，`britishhorseracing.com/?p=2795`，
RHT 原始新闻稿级来源）：

| GoingIndex | 官方 going |
|---|---|
| 1.0 – 2.9 | **Heavy**（重） |
| 3.0 – 4.9 | **Soft**（稍重/软） |
| 5.0 – 6.9 | **Good to Soft** |
| 7.0 – 8.9 | **Good**（良，基准） |
| 9.0 – 10.9 | **Good to Firm** |
| 11.0 – 12.9 | **Firm** |
| 13.0 – 15.0 | **Hard**（英国几乎不用，会洒水避免） |

- 仪器由 **TurfTrax** 与 **Cranfield University** 联合开发，测**两个力**：
  **垂直穿透（penetration）** + **拉到 45° 的剪切（shear）**，加权后复现马蹄冲击。
  开发期累计 **>60,000 次读数**。
- **两条重要警告**：
  1. **读数与赛道绑定**，跨赛道不可直接比——Goodwood 的"良"（白垩土排水快）
     ≠ 低洼黏土赛道的"良"。
  2. **它测的是"静置地面"，不是"承重地面"**——
     真正影响马匹的是 500 kg 全速冲击下的 hoof–turf 相互作用（这正是上节 NTU 研究要补的）。

### 真实赛事计时的量级锚点（把"约 1.7%/档"落到秒）

以下均为公开赛事计时/分析，**非同行评审，但给的是可核对的具体场次**：

- **口径差异（欧洲大陆 vs 英爱）**：法国用**穿透仪（penetrometer）降序刻度**
  （数字越小越软），英爱用 GoingStick。France Galop 约 2022 年起**并行**使用 GoingStick。
  经验换算：**法国的 soft ≈ 英爱的 good to soft**（法国读数整体偏软一档）。
  → 若日后要抓法国/日本数据，**必须先对齐口径，否则会凭空多出一档误差**。
  （Racing Post，2025 年凯旋门周报道）
- **同场同程、只差地面的极端对比——2012 vs 2016 七月杯（Newmarket 6f）**：
  - 2012 年（**heavy**）：Mayson 造出 **1:15.90**（一代人最慢）；
  - 2016 年（快地）：Limato **1:09.97**。
  - **同一赛事同一距离，相差约 5.93 秒**。
    → 在"现实残差 5% 门槛"的语言里，**这一项单独就能吃掉全部误差预算**，
      所以**在比较不同赛事的绝对用时前，必须先做 going 归一化**。
- **凯旋门（Longchamp 2400m）对标准时间的残差**：
  Lammtarra 1995（very soft）仅慢标准 **1.30 s**；Treve 2013（soft）慢 **1.54 s**；
  而 2000 年代中期 good to soft 下 Hurricane Run / Dylan Thomas / Zarkava 均**快于标准**。
  → **软地并不必然"大幅变慢"**——2400m 顶级赛事里软地残差只有 1.3–1.5 s。
    这与"软地拖慢短途最多"（见下条步幅机制）方向一致：**距离越长，going 的相对效应越小**。
- 民间经验值（**非同行评审**，仅供参考）：同赛道同距离，**firm vs heavy 一英里约差 3–4 s**。

### 机制层：步幅缩、频率不变（能直接对上引擎的 stride/frequency 分解）

来自 **StridePredictor**（100 匹马、每匹跨两种 going、均为"真实跑满"赛事并做时间评级筛选；
**非同行评审**。原文：`stridepredictor.com/how-going-affects-racehorse-stride/`）：

| going 变化幅度 | 步幅损失 | 速度损失 |
|---|---|---|
| **1 档**（如 good to firm → good） | **−1.2%** | **−1.7%** |
| **2 档**（如 good → soft） | **−3.9%** | **−4.3%** |
| **3 档**（如 good to firm → soft） | **−6.6%** | **−7.6%** |

- **关键机制结论**：速度损失**几乎全部来自步幅缩短**；
  **步频几乎不动**（**79%** 的马步频比步幅更稳定）。
  → 因为 `速度 = 步幅 × 步频`，步频恒定 ⇒ **速度损失 ≈ 步幅损失**。
- 一档变化时**约 1/3 的马测不到步幅损失**（个体差异大）；两档时 90% 掉步幅；三档时**全部**掉。
- 分距离（混合各档）：**短途 −4.2%、中距离 −2.6%、长距离 −4.0%**
  （短途最脆弱：本已接近机械极限，可回旋余量最小；中距离反而最耐受）。
- ⚠️ **原文自曝的一个反面教训（很有价值）**：
  该机构曾尝试"把每匹马的步幅数据**标准化回良地基准**"，结果**预测精度下降**——
  因为模型**本来就已经通过步幅间接看到了 going 效应**，再叠加一层修正等于**双重扣除**。
  → 与本项目纪律一致：**going 应作为一个机制进入动力/步幅，而不是在结果上乘一个修正系数。**

**【对本项目】四条结论：**

1. **going 应作为"机制"进入（方法 3 = 补机制），不是结果端乘系数。**
   现实证据是"软地 → 步幅缩短 → 速度下降"，且**步频基本不变**。
   若引擎已有 stride/frequency 分解，最"拟合现实"的接法是**给步幅加一个随 going 的缩减项**，
   而不是在完赛用时上做线性补偿。这也正是 StridePredictor 自曝踩过的坑。
2. **响应是单调饱和的，不要当线性量。**
   cushioning 在 10 kN 处出现平台（≈2 倍马体重）：**硬化端饱和、软化端陡**。
   本项目若引入 going，应实现为**分段/饱和曲线**；一刀切的线性系数会在两端同时失真，
   重蹈"加参数轴凑指标"的老路。
3. **going 档位表可直接借用，但要守住两条警告。**
   档位：Heavy / Soft / Good to Soft / Good / Good to Firm / Firm / Hard
   （GoingIndex 见上表）。**同档位在不同赛道不等价**，且 GoingStick 测的是**静置**地面
   → 本项目若做多赛道，**going 与赛道要联动标定，不能全局共享一个系数**。
4. **软地提高方差 ⇒ 这可能正是"完赛密度未拟合"缺的那一块。**
   现状：冠军后 1 s 内比例 现实 **76.8%** vs 模拟 **~18%**（−62.5 pp）。
   NTU 研究明确指出**软地上速度变异性显著更高**，且这层方差**来自地面而非骑手**。
   而我们所有场次都跑"良地"，等于把这部分结构性方差**抹掉了**。
   → **以"重地/软地场次"为对照组做一轮对照实验**，是验证"缺的是 going 机制"
     这一假设的最直接办法（对照本项目的三步诊断法：先排除调数值，再查机制）。
