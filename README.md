## 30 秒玩法

- 1968 年 6 月开局，52 周/年的真实赛程日历：新马赛（6~12月）、未胜利、一胜~三胜、表列赛、G3/G2/G1（G1 压轴），全年约 356 场
- 每周情报会点评赛程中的马——**但有误差**（相马眼/洞察力等级决定误差大小），赛后揭穿 ✓/✗
- 六种马券：単勝/複勝/馬連/馬単/三連複/三連単，赔率由单胜赔率推导
- 马群 70+ 匹自运转：战绩逐场累积、每年老化退役、**新马由繁殖公式生成**——你压中的超马可能伤退，两年后它的儿子会带着它的血统出现在新马赛
- 观赛是转播视角：镜头跟马群、过弯跑道转弯、実況解说
- 每周生活费 -1万，破产可重置——随机下注期望回报 83%，**看穿情报才能活**

## 三个模式

| 模式 | 内容 |
|---|---|
| 💰 赌马生涯 | 核心玩法：看情报 → 下注 → 观赛 → 周结算 → 交生活费 |
| 🔬 繁殖模拟 | 公式验证工具：选父母马配种，看幼驹真实数值 + 蒙特卡洛分布图，幼驹可入厩追踪 |
| 🎬 单场模拟 | 比赛引擎沙盒：自由编辑每匹马的隐藏数值，切换"文档原版/平衡修正"系数对比 |

## 验证报告

### 跑法胜率蒙特卡洛（每档 200 场）

调参前后对比，四种跑法胜率向 25% 收敛：

| 跑法 | 文档原版系数 | 平衡修正后 |
|---|---|---|
| 逃 | 14.5% | 22.0% |
| 先 | 8.5% | 10.0% |
| 差 | 49.0% | 37.5% |
| 追 | 28.0% | 30.5% |
| **极差** | **40.5%** | **27.5%** |

### 冠军-亚军着差（2000 场配对比赛）

| 指标 | 文档原版系数 | 平衡修正后 |
|---|---|---|
| 中位数 | **10.99 马身** | **4.86 马身** |
| 平均值 | 13.88 | 6.20 |
| 最大 | 96.39 | 72.58 |

修复项：马群跟跑耦合 + 属性向全场均值回归 + 跑法系数收敛 + 爆发因子 0.25→0.10。
着差中位数收敛 **55.8%**，大差逃切与鼻差绝杀两种结局都保留。

### 测量方法说明（为什么之前的临时统计不可信）

让那匹 +5 属性的强马轮转全部 8 个闸位（闸位对应不同跑法）后，四种跑法的胜率
**整体再漂移 12~18 个百分点**——这个幅度比跑法系数本身还大。

所以统计方式必须是：「锁定强马落点 + 对比组同种子同阵容」，否则强马随机落在哪个闸位，
就会把系数的真实效应整个盖掉。**这也是本脚本存在的意义**：调参前先有一个能复现的测量工具，
才知道改动到底有没有用。

### 繁殖公式蒙特卡洛（100 次，双 90 速度父母）

| 指标 | 实测 | 结论 |
|---|---|---|
| 早夭率 | 4.5% | 接近文档 5% |
| 子代速度 | 均值 65.3 ± 10.2 | 强均值回归（权重特性），极端个体存在 |
| 状态值 | 上限实为 19800 | 文档"0-15000"与其转换公式不一致 |
| 种费 | G1 种马 1000 万 | 落在文档 800~1500 区间 |

### 复现方式

```
node tests/mc.js   [跑法场次] [着差场次] [每闸位场次]   # 默认 200 2000 200
node tests/diag.js [每档场次]                          # 属性模板与强马落点诊断
```

两个脚本只依赖 `../sim.js`，纯 Node、零依赖、无构建，约 12 分钟跑完。
对比组使用**完全相同**的马匹阵容与随机种子，唯一变量是系数档位（骑手固定「普通」、疲劳归零），
因此差异可归因到系数本身。比赛为确定性模拟（同种子同结果），所有数字可逐位复现。

## 技术说明

纯 JavaScript（零依赖、零构建），单页面 + 一个引擎文件（sim.js，约 1643 行），双击即玩；
引擎与 UI 分离，公式全部带文档章节注释。比赛为确定性模拟（同种子同结果），适合回归测试。
