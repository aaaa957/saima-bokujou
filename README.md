## 30 秒玩法

- 1968 年 6 月开局，52 周/年的真实赛程日历：新马赛（6~12月）、未胜利、一胜~三胜、表列赛、G3/G2/G1（G1 压轴），全年约 356 场
- 每周情报会点评赛程中的马——**但有误差**（相马眼/洞察力等级决定误差大小），赛后揭穿 ✓/✗
- 六种马券：単勝/複勝/馬連/馬単/三連複/三連単，赔率由单胜赔率推导
- 马群 70+ 匹自运转：战绩逐场累积、每年老化退役、**新马由繁殖公式生成**——你压中的超马可能伤退，两年后它的儿子会带着它的血统出现在新马赛
- 观赛是转播视角：镜头跟马群、过弯跑道转弯、実況解说
- 每周生活费 -1万，破产可重置——随机下注期望回报 83%，**看穿情报才能活**

|---|---|
| 💰 赌马生涯 | 核心玩法：看情报 → 下注 → 观赛 → 周结算 → 交生活费 |

## 验证报告

> **以下数字全部由 `tests/mc.js` 跑出，可复现**：`node tests/mc.js 200 2000 200`
> 脚本与本文件同级目录，引擎经 `module.exports` 引入，纯 Node 运行、无需浏览器。
> 测量条件：2000m 草地・良・缓坂・8 匹出马（4 种跑法各 2 匹），对比组使用**完全相同**的马匹阵容与随机种子，唯一差异是 `styleCoefs` 档位。

### ① 跑法胜率对比（每档 200 场）

| 跑法 | 文档原版 | 平衡档 | 理想值 |
|---|---|---|---|
| 逃 | 14.5% | 22.0% | 25% |
| 先 | 8.5% | 10.0% | 25% |
| 差 | 49.0% | 37.5% | 25% |
| 追 | 28.0% | 30.5% | 25% |
| **极差** | **40.5%** | **27.5%** | 0 |

平衡档把胜率极差从 40.5% 压到 27.5%，但**没有修好**——`先` 仍只有 10.0%。原因见 ③。

### ② 冠军-亚军着差（马身）对比（2000 场配对比赛）

| 指标 | 文档原版 | 平衡档 |
|---|---|---|
| 中位数 | **10.99 马身** | **4.86 马身** |
| 平均值 | 13.88 | 6.20 |
| 最大 | 96.39 | 72.58 |

修复（马群跟跑耦合 + 属性回归 + 系数收敛 + 爆发因子 0.25→0.10）后中位数收敛 **55.8%**，
大差逃切与鼻差绝杀两种结局都还在。

### ③ 强马落点影响（strongIndex 轮转 0~7，每档 1600 场）

| 跑法 | 文档原版 | 平衡档 |
|---|---|---|
| 逃 | 23.4% | 27.8% |
| 先 | 21.4% | 17.8% |
| 差 | 21.4% | 18.1% |
| 追 | 33.7% | 36.4% |
| **极差** | **12.3%** | **18.6%** |

**这一节是本次验证最有价值的发现，也是一个尚未解决的问题**：真实比赛里那匹 +5 属性的强马
会落在随机闸位上，而闸位对应不同跑法（`makeField` 按 逃/先/差/追/先/差/追/随机 排列）。
强马落点带来的胜率波动（12~18 个百分点）**大于跑法系数本身**，把系数的差异掩盖掉了——
这也是为什么临时跑几十场统计会得到极不稳定的结论。

配套诊断脚本 `tests/diag.js` 进一步定位：四种跑法的**属性模板本身不平衡**，
`爆发力` 一项从 逃 58 到 追 82 跨越 24 点，而爆发力只在终盘生效
（`pot = base × (burstFactor × 爆发力/100 + runCoef)`），这让高爆发跑法在终盘拿到压倒性优势。

**结论：跑法失衡不能只靠调跑法系数解决，需要同时调属性模板与爆发因子。**
这一步留作后续工作（todo）。

### 繁殖公式蒙特卡洛（100 次，双 90 速度父母）

| 指标 | 实测 | 结论 |
|---|---|---|
| 早夭率 | 4.5% | 接近文档 5% |
| 子代速度 | 均值 65.3 ± 10.2 | 强均值回归（权重特性），极端个体存在 |
| 状态值 | 上限实为 19800 | 文档"0-15000"与其转换公式不一致 |
| 种费 | G1 种马 1000 万 | 落在文档 800~1500 区间 |

> 注：页面上「📊 蒙特卡洛100次」按钮实际抽样 100 次（`index.html` 的 `drawBreedChart()`）。
> 上表为多次抽样的汇总观察，不是单次点击的直接输出。

## 数值验证脚本

```
node tests/mc.js   [跑法场次] [着差场次] [每闸位场次]   # 默认 200 2000 200
node tests/diag.js [每档场次]                          # 属性模板与强马落点诊断
```

两个脚本都只依赖 `../sim.js`，纯 Node、零依赖、无构建。比赛为确定性模拟
（同种子同结果），因此上述所有数字可逐位复现。

## 技术说明

纯 JavaScript（零依赖、零构建），单页面 + 一个引擎文件（sim.js，约 1643 行），双击即玩；
引擎与 UI 分离，公式全部带文档章节注释。比赛为确定性模拟（同种子同结果），适合回归测试。
