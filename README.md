## 30 秒玩法

- 1968 年 6 月开局，52 周/年的真实赛程日历：新马赛（6~12月）、未胜利、一胜~三胜、表列赛、G3/G2/G1（G1 压轴），全年约 356 场
- 每周情报会点评赛程中的马——**但有误差**（相马眼/洞察力等级决定误差大小），赛后揭穿 ✓/✗
- 六种马券：単勝/複勝/馬連/馬単/三連複/三連単，赔率由单胜赔率推导
- 马群 70+ 匹自运转：战绩逐场累积、每年老化退役、**新马由繁殖公式生成**——你压中的超马可能伤退，两年后它的儿子会带着它的血统出现在新马赛
- 观赛是转播视角：镜头跟马群、过弯跑道转弯、実況解说
- 每周生活费 -1万，破产可重置——随机下注期望回报 83%，**看穿情报才能活**

## 三个模式

| 模式 | 内容 |
|---|---|
| 💰 赌马生涯 | 核心玩法：看情报 → 下注 → 观赛 → 周结算 → 交生活费 |
| 🔬 繁殖模拟 | 公式验证工具：选父母马配种，看幼驹真实数值 + 蒙特卡洛分布图，幼驹可入厩追踪 |
| 🎬 单场模拟 | 比赛引擎沙盒：自由编辑每匹马的隐藏数值，切换"文档原版/平衡修正"系数对比 |

## 验证报告

### 缺陷 1：文档原版跑法系数下，追马永远追不上逃马

按公式推演：逃马出闸/序盘 1.08 对追马 0.88，前 1200m 累积约 136 米，终盘爆发修正追不回——蒙特卡洛 200 场逃马胜率近半。**对策**：内置"平衡修正"系数档（可切换对比），四种跑法胜率收敛到 22%~33%。

### 缺陷 2：马身被公式放大 30 倍

量化诊断出四个放大源（基础速度斜率：5 点属性差 = 全程 60 马身；跑法系数早期差距 136 米；爆发修正 0.25 造成终盘 24 马身差；**缺马群跟跑耦合**——马各跑各的，差距从第 1 米线性累积）。修复（跟跑耦合 + 属性回归 + 系数收敛）后：冠军-亚军中位数 **27.7 → 5.5 马身**，保留大差逃切与鼻差绝杀两种戏剧性结局。

### 繁殖公式蒙特卡洛（1000 次，双 90 速度父母）

| 指标 | 实测 | 结论 |
|---|---|---|
| 早夭率 | 4.5% | 接近文档 5% |
| 子代速度 | 均值 65.3 ± 10.2 | 强均值回归（权重特性），极端个体存在 |
| 状态值 | 上限实为 19800 | 文档"0-15000"与其转换公式不一致 |
| 种费 | G1 种马 1000 万 | 落在文档 800~1500 区间 |

## 技术说明

纯 JavaScript（零依赖、零构建），单页面 + 一个引擎文件（sim.js，约 2300 行），双击即玩；引擎与 UI 分离，公式全部带文档章节注释。比赛为确定性模拟（同种子同结果），适合回归测试——内置自检模式（index.html#autotest）。
